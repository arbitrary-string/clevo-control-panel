# Contributing to This Project

We love contributions! To keep things running smoothly, please follow these simple rules:

## 1. Ground Rules
* **Follow the Code of Conduct**: Be respectful and don't act like a fool.
* **Keep it Focused**: Solve one specific bug or add one specific feature per pull request.

## 2. Technical Steps
* **Open an Issue First**: Before writing code, open an issue to discuss what you want to change. This ensures your hard work doesn't get rejected.
* **Write Clean Code**: Follow existing code styles and ensure the project still compiles/runs before submitting.
* **Sign Your Work**: By submitting a pull request, you explicitly agree that your code will be released under the GNU GPL v3 license.

## 3. How to Submit
1. Fork this repository.
2. Create a branch for your fix (`git checkout -b feature/amazing-fix`).
3. Commit your changes and push to your fork.
4. Open a Pull Request back to this repository with a clear description of what you changed.
