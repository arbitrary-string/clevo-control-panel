# Security Policy

## Supported Versions
We only actively patch the latest release of this software. If you find a bug, please update to the newest version to see if it has already been fixed.

## Reporting a Vulnerability
**Please do not open a public issue for security flaws.** 

To report a vulnerability safely:
1. Go to the **Security** tab at the top of this GitHub repository.
2. Click **Vulnerabilities** on the left menu.
3. Click **Report a vulnerability** to submit a private report.

If you prefer email, you can reach the maintainer privately at: arbitrarystring@gmail.com

We will review your report and get back to you as soon as possible. Thank you for helping keep this project secure!
